Formula Yaad Kar Lo

As a [User]
I want [Feature]
So that [Benefit]

3 Real Examples

JIRA-101 High Priority

As a Swiggy user,
I want delivery ka OTP dikhe,
So that galat delivery na ho.

Acceptance: OTP 4 digit, Map pe dikhega
JIRA-102 Medium

As a new user,
I want pehle order pe 50% off,
So that main try kar saku.

Acceptance: Coupon auto-apply hoga
