🎤 PM Interview

Top 5 Questions Jo Har Jagah Puchte Hai

Q1. Swiggy ka order kam ho gaya, kya karogi?
CIRCLES se bolo: User pata karo kaunsa city, data dekho kab se kam hua, kahi competitor aaya kya, phir solution.
Best Ans: "Pehle data se check karungi kaunse user kam hue, phir 5 user se call karke puchungi kyu chod diya"
Q2. Favorite product kaunsa hai aur kyu?
WhatsApp / Notion / Zerodha bolo, teardown jaisa bolo.
Best Ans: "Notion favorite hai - Simple hai, par powerful hai. 1 problem: Mobile pe slow hai, main offline mode fast karti"
Q3. Ek naya feature batao Instagram ke liye
Problem se start karo, user kaun hai batao.
Best Ans: "Students ke liye 'Study Mode' - Reels band, sirf educational content. Exam time pe retention badhega"
Q4. Developer bole ye feature nahi banega, kya karogi?
Ladai nahi, data se baat.
Best Ans: "Effort puchungi, kya chhota karke ban sakta hai? Agar nahi toh priority change karke dusra feature lungi"
🔥 Final Tip
Har answer me: User + Data + Number bolo. "Mujhe lagta hai" mat bolo, "Data ke hisab se" bolo.
