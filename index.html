👨‍💼 1. PM Kya Hota Hai? - Basti

Simple Definition: Product Manager matlab Product ka Maa-Baap - Jaise ghar me mummy sab sambhalti hai, waise PM product sambhalta hai. User ko kya chahiye, dev ko kya banana hai, business ko paise kaise ayenge - sab PM sochta hai.
🎬 Filmy Example: Socho Film banti hai - Director = PM, Hero (Developer) ko batayega kya karna hai, Story (User Problem) samjhega, Producer (Business) ko profit dilayega.
🧠 3 Kaam PM Ke:
1️⃣ User Samjho: Logon ko dikkat kya hai?
2️⃣ Solution Banao: Uska hal kya hai?
3️⃣ Team Se Banwao: Design, Dev, QA sabko saath leke chalo

2. PM vs Project Manager

PM: KYA banana hai? User ko kya chahiye, kyun chahiye.
Project Manager: KAB tak banana hai? Timeline, resources.
PM = Strategy, Project Manager = Execution. Basti me dono ek hi karta hai shuru me.

4. User Story

Formula: As a [user], I want [feature], so that [benefit].
Example: As a 12th PCM student Basti se, I want Hindi me PM notes, so that CSE BTech me help ho.
